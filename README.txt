Весільний сайт Євгеній & Христина — перша версія.
Відкрийте index.html у браузері (потрібне підключення до інтернету лише для вебшрифтів).
Натисніть на конверт, щоб побачити анімацію. Значок конверта у верхньому правому куті повторює вступ.
У папці assets розміщено всі 11 надісланих фотографій та фото-референс конверта.
ВАЖЛИВО: RSVP поки не надсилає відповіді на сервер, а копіює текст у буфер обміну. Для справжнього збору відповідей потрібне підключення бази даних/форми.
Місце проведення та точний час не вказані, оскільки ще не були надані.
Для публікації можна використати GitHub Pages, Netlify або Cloudflare Pages.
